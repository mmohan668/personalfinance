Helpful Tips

  • Select the appropriate record before using Copy, Edit, Delete, Activate, or Inactivate.
  • Review your selected rows before exporting selected records.
  • Use the Column Chooser to display only the fields you need.
  • Save your grid settings after customizing your preferred layout.
  • Use Reset Grid Settings to restore the default layout.
